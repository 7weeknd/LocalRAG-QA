# 常见问题FAQ

## 如何修改绑定手机号？

进入"我的 → 设置 → 账户与安全 → 手机号"，验证原手机号短信验证码后即可绑定新号码。若原手机号已停用无法接收验证码，请联系在线客服并提供实名认证信息进行人工换绑。

## 如何注销账号？

账号需无未完成订单、无余额、无纠纷售后，方可注销。路径：我的 → 设置 → 账户与安全 → 注销账号。注销后所有积分、优惠券、订单记录将被清除且无法恢复，请谨慎操作。

## 商品是正品吗？

平台所有自营商品均为品牌直供或官方授权，支持假一赔十。第三方店铺商品请认准"官方旗舰""品牌授权"标识。如收到商品质疑真伪，可持商品到品牌官方网点检测，凭检测报告申请赔付。

## 如何联系人工客服？

在线客服：APP首页右下角"客服"入口，输入"人工"即可转接，服务时间每天8:00-24:00。黑金会员享7×24小时专属客户经理。电话客服：400-000-0000。

高峰期（如大促前后）排队人数较多，建议您先描述问题并附上订单号和截图，客服接入后可更快处理。
